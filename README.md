## ✨ Features We Offer

- **Smart Crowd Management:** AI-based CCTV heatmaps for real-time crowd monitoring  
- **Priority Ticketing:** Tiered access, QR/face-based entry, overload prevention  
- **Smart Navigation:** Live maps with crowd-aware alternate routes  
- **VIP & Emergency Routing:** Automated, congestion-free movement planning  
- **Live Darshan:** Web-based live streaming with digital queue access  
- **AI Lost & Found:** Face, image, and text matching using Google Gemini  
- **Dynamic Alerts:** Real-time notices, weather & emergency notifications  
- **Public Transport Integration:** Shuttle & bus optimization with live data  
- **Inclusive Access:** Dedicated routes for elderly & Divyangjan  
- **Scalable & Secure:** Cloud-native, role-based access, encrypted data  

---

## 💡 Proposed Solution

**Divya Yatra** is an **AI-powered smart pilgrimage management platform** designed for **Simhastha 2028**.

The system focuses on:
- Smart mobility  
- Crowd intelligence  
- Safety & emergency handling  
- Digital engagement for pilgrims

## ☁️ Google Technologies Used

- **Google Gemini AI** – AI-powered Lost & Found  
- **Google Cloud Platform** – Scalable backend & AI workloads

- **Firebase** – Authentication, alerts, and notifications  
- **Google Vision API** – CCTV-based crowd analytics  

---

## 🔄 Workflow & System Flow

- **Frontend:** React.js web/mobile interface  
- **Maps:** Leaflet.js for navigation  
- **Real-Time Updates:** Socket.IO  
- **Backend:** Node.js + Express.js (REST + WebSockets)  
- **Authentication:** Firebase Google Sign-In  
- **Chatbot & Planner:** Twilio, n8n, Webhooks  
- **AI & Data:** Google Gemini, CCTV analytics  
- **Admin Dashboard:** Central control panel  

---

## 🏗️ Technical Architecture

### Frontend Layer
- **Tech:** React.js, Leaflet.js, Socket.IO  
- User dashboards (pilgrims & admins)  
- Live maps, ticket booking, darshan streaming  

### Backend Layer
- **Tech:** Node.js, Express.js, REST APIs, WebSockets  
- Ticketing, QR generation, alerts, AI integration  

### Database Layer
- **Tech:** SQL (MySQL / PostgreSQL)  
- Pilgrim data, tickets, crowd logs, lost & found  

### AI/ML Layer
- **Face Recognition:** Python, OpenCV  
- **Crowd Detection:** YOLOv5, OpenCV  
- Real-time heatmaps & alerts
